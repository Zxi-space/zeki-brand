# Naming Conventions

## 1. 原则

- 名称应易读、易记、易拼写；
- 避免与现有知名产品造成明显混淆；
- 不为追求统一而给所有产品机械添加前缀；
- 产品名称与仓库 ID 分离：展示名可调整，ID 尽量稳定；
- 正式使用前应检查域名、商标和同名产品风险；本仓库不代表已经完成法律检索。

## 2. 品牌名称

- 主品牌：`Zeki`
- 伴侣称呼：`Kiki`
- 双人表达：`Zeki & Kiki`
- 域名：`zekiki.cc`

大小写按上述形式使用；代码标识和目录使用小写。

## 3. 产品命名建议

可采用以下模式，但不是强制前缀：

- `Zeki + 描述性词语`：适用于明确归属于个人品牌的产品；
- 独立产品名 + `by Zeki`：适用于需要独立品牌个性的产品；
- `Zeki & Kiki + 产品名`：适用于双方明确共同创作的产品。

## 4. ID 规则

- 全小写 kebab-case；
- 只使用英文字母、数字和连字符；
- 创建后不因展示名修改而随意更改；
- 不复用已归档产品 ID。

示例：

```text
zeki-home
zeki-us
idea-image-workbench
```

以上仅为命名示例；具体产品名需单独确认。
