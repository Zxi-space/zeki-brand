# Brand Messaging

## 1. 核心表达（工作版本）

中文工作表达：

> 把想法做成真实可用的产品，并记录创造过程。

英文候选表达：

> Make ideas real.

状态：**候选 / 待品牌主最终确认**。在正式确认前，不要将其标记为唯一官方 Slogan。

## 2. 品牌介绍层级

### 极短介绍

Zeki — 独立创造者，持续构建数字产品。

### 标准介绍

Zeki 是一个以独立创造为核心的个人品牌，关注全栈开发、数字产品、创意实验和持续记录。

### 扩展介绍

我喜欢把有趣且有价值的想法变成真实可用的产品。从个人网站、效率工具到实验性应用，我会记录产品从构想到实现的过程，也分享技术实践与迭代经验。部分项目会与 Kiki 共同创作。

以上均为文案草稿，不构成已发布的正式宣传材料。

## 3. 信息表达原则

- 先说明产品解决什么问题，再说明使用了什么技术。
- 优先使用可验证的事实和具体成果。
- 清楚区分 Idea、Prototype、Development 和 Active。
- 少用“颠覆”“革命性”“行业领先”等无法证明的形容词。
- 面向用户的文字应清晰、直接、易理解。
- 技术文章可以使用准确的工程术语，但避免无必要的术语堆砌。

## 4. 禁止误导

不得虚构用户数、收入、下载量、客户、合作伙伴、性能指标、认证或产品上线状态。未经确认，不得声称某个产品由 Zeki 与 Kiki 共同开发。
