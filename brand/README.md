# Brand

本目录维护 Zeki 品牌的长期策略与表达规范。

| 文件 | 内容 |
|---|---|
| `positioning.md` | 品牌定位、受众假设与价值 |
| `story.md` | 品牌故事与人物关系 |
| `messaging.md` | 核心表达、介绍文案和 Slogan 状态 |
| `personality.md` | 品牌人格、语气和表达边界 |
| `brand-architecture.md` | Zeki、Kiki 与共同项目的品牌关系 |
| `naming-conventions.md` | 品牌、产品和项目命名规则 |

本目录中的“工作定位”和“候选表达”可迭代；涉及主品牌名称、人物关系和权利边界的变更需要品牌主确认。
