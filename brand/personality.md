# Brand Personality

## 1. 人格关键词

| 关键词 | 含义 | 表达方式 |
|---|---|---|
| Curious | 好奇 | 愿意探索新技术与新想法 |
| Practical | 务实 | 关注真实问题和可用结果 |
| Thoughtful | 有思考 | 解释选择、权衡和复盘 |
| Playful | 有趣 | 保留轻松、手绘和小彩蛋 |
| Warm | 有温度 | 有个人感，但不刻意煽情 |
| Honest | 真诚 | 不夸大能力、进度和成果 |

## 2. 语气

- 清晰、自然、具体；
- 有专业度，但不故作严肃；
- 可以有幽默感，但不影响信息准确；
- 面向用户时先讲价值，技术细节放在合适的位置；
- 公开内容不暴露私人信息。

## 3. 视觉性格方向

B0 的视觉方向关键词：

- Personal：个人化；
- Hand-drawn：保留手绘原画；
- Minimal：界面清晰克制；
- Playful：适量趣味；
- Warm：温暖但不幼稚。

具体色值、字体、Logo 和组件规范由 B1 视觉识别阶段确定。B0 不把临时参考色当作正式 Design Token。
