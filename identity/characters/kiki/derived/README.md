# Kiki — Derived Assets

当前暂无衍生素材。

新增衍生素材时，请使用独立文件名，并在此目录或资产清单中记录：

- asset ID；
- 对应原始素材路径；
- 处理方式（裁切、抠图、调色、重绘、动画等）；
- 输出尺寸和格式；
- 创建日期；
- 创作者/操作者；
- 使用范围与许可状态。

不得覆盖 `../original/kiki-original.png`。
