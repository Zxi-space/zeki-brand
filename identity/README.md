# Identity System

本目录维护品牌视觉资产和使用规范。

B0 先建立资产结构、原始角色保护规则和视觉方向。正式 Logo、色彩 Token、字体系统、图标规范、组件规范和角色衍生素材属于 B1。

## 目录

- `visual-guidelines.md`：当前视觉方向和待定事项；
- `characters/`：角色原画、资产清单和衍生素材；
- 后续可增加 `logo/`、`colors/`、`typography/`、`design-tokens/`、`icons/`。

## 资产原则

原始文件不可覆盖；衍生文件必须可追溯到原始素材；公开或商业使用前确认创作者许可范围。
