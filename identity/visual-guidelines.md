# Visual Guidelines — B0

## 1. 当前视觉方向

品牌视觉以两张真实手绘角色原画为起点，保留纸感、手绘线条和个人创作痕迹。

方向关键词：

- 温暖、轻松、个人化；
- 现代、清晰、留白充足；
- 手绘角色作为品牌识别元素，而不是每个页面都必须出现的装饰；
- 不将原画擅自转成 3D、矢量或其他风格。

## 2. 页面设计原则

1. 内容优先，角色插画作为辅助叙事。
2. 个人主页可以更具表现力；工具产品可以更偏效率和可读性。
3. 产品间允许拥有不同的信息架构和 UI 风格。
4. 共享的应是品牌署名、资产来源、核心语气和必要的识别元素。
5. 优先保证响应式、可访问性、性能和内容可读性。

## 3. 当前未定项

以下内容不在 B0 中擅自定稿：

- Logo 的最终形态；
- 正式品牌色及语义色；
- 字体组合；
- 角色标准比例、表情和动作库；
- 插画线条与纹理规范；
- 动效规范；
- 产品间共享组件规范。

## 4. 参考色的处理

此前讨论过的奶油白、墨黑、暖棕、柔和蓝和浅粉仅是方向性参考，不是正式色值。B1 应从原画和实际界面中重新取样、验证对比度，并生成正式 Design Tokens。
