## 1. Product

**Zeki Inspector**

A lightweight browser web inspection tool presented as a **horizontal floating toolbar**.

核心产品概念：

> 轻量的浏览器网页检查工具，以「水平悬浮工具栏」的形式出现。帮助你快速检查页面元素、理解结构、定位问题，并辅助开发构建。

## 2. Brand Promise

**Inspect. Understand. Locate. Build.**

中文表达：

**检查元素，理解结构，精准定位，辅助构建。**

品牌表达不强调“复杂的开发者控制台”，而强调“在页面上直接看、选、定位、复制和理解”。

## 3. Core Scenarios

- 快速检查页面元素 / Inspect page elements quickly
- 理解页面结构 / Understand page structure
- 精准定位问题 / Locate issues accurately
- 辅助开发构建 / Assist in development & building

## 4. Product Form

Zeki Inspector 的核心 UI 是页面内的**横向悬浮工具栏**。

不以管理后台、常驻侧边栏或 DevTools 式多栏面板作为主要产品形态。

核心交互：

1. Select
2. Multi
3. Parent / Child
4. Prev / Next
5. Copy Selector
6. Copy Locator
7. Screenshot
8. AI Context
9. More
10. Close

## 5. Brand Character

**Warm Precision / 温和的精确**

- 温和：来自手绘角色、Cream 背景、柔和色彩和轻量圆角。
- 精确：来自元素选择、定位器、DOM/Locator 信息和明确的操作反馈。
- 友好：避免冰冷的纯技术工具视觉。
- 克制：避免过度玻璃拟态、霓虹、流光和高饱和科技效果。

## 6. Positioning Boundary

Zeki Inspector 不是：

- 一个完整的浏览器 DevTools 替代品；
- 一个后台管理系统；
- 一个常驻侧边栏式页面管理器；
- 一个页面设计编辑器。

它首先是一个**快速、直接、可视化的网页元素检查工具**。

## 7. Relationship to Zeki Brand

Zeki Inspector 是 Zeki 品牌旗下独立产品。

产品视觉直接继承 Zeki 的角色资产与手绘表达，但在产品 UI 中保持更强的信息秩序、操作反馈和开发工具属性。
