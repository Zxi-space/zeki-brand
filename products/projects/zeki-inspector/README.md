# Zeki Inspector — Brand & Product Assets v1.0

This package consolidates the approved visual assets from Batch 01, Batch 02,
and Batch 03 into the `zeki-brand/products/zeki-inspector/` structure.

Start here:
1. `ASSET-CATALOG.md` — asset map and usage rules.
2. `asset-manifest.json` — file inventory, dimensions, transparency, and hashes.
3. `brand/` — product brand guidelines.
4. `design-system/` — Light/Dark CSS and design tokens.
5. `assets/` — production-ready image assets.

The approved mascot source is `assets/logo/logo-mark-source.png`.
