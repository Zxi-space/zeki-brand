# Batch 03 — Product Illustrations

All five accepted illustrations are supplied as standalone transparent PNGs.

| File | Intended use |
|---|---|
| `empty-state/empty-state-inspector.png` | No selected element / empty inspection state |
| `selection/element-selection-success.png` | Element selection completed successfully |
| `ai-context/ai-context-detective-workflow.png` | AI Context / context extraction explanation |
| `onboarding/welcome-illustration.png` | Welcome screen and onboarding entry |
| `feedback/curious-hint-moment.png` | Tips, hints, and lightweight guidance |

Use the PNGs as image assets. Keep the original aspect ratio; use `object-fit:
contain` and avoid cropping the character, magnifying glass, or focus-corner
motif. The files are preserved as generated and are not redrawn in this package.
