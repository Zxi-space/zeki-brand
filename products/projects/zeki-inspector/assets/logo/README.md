# Zeki Inspector Logo Assets

## Approved source

`logo-mark-source.png` is the exact final mascot artwork supplied by the user
(the last approved image in the source batch). All logo and icon outputs in this
batch are derived from that file. The character, magnifying glass, green focus
corners, colors, texture, and proportions have not been redrawn or recolored.

## Files

- `logo-mark.png`: full-resolution transparent master (1254 × 1254).
- `logo-mark-1024.png`, `logo-mark-512.png`, `logo-mark-256.png`,
  `logo-mark-128.png`, `logo-mark-64.png`: transparent raster exports.
- `logo-mark.svg`: SVG wrapper containing the exact transparent PNG as an
  embedded image. It is convenient to embed in web projects, but it is NOT
  path-level vector artwork. This avoids falsely claiming that the textured
  mascot has been converted into editable vector paths.

## Usage

Use the transparent PNG for UI, web, toolbar and documentation placements.
Use the app icon exports for operating-system/app tiles and the extension icon
exports for Chrome/Edge extension manifests.
